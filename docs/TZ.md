# Техническое задание: сайт книжного магазина «Переплёт»

**Вариант 9 — «Магазин книг».** Особенность варианта: подборки по жанру и список «Прочитать позже».

## Назначение

Сайт небольшого книжного магазина. Посетитель выбирает книгу по жанру и цене, смотрит подробную информацию,
складывает книги в корзину и оформляет заказ. Зарегистрированный пользователь ведёт список «Прочитать позже».

## Страницы

| № | Страница | Файл | Содержимое | Что может сделать пользователь |
|---|---|---|---|---|
| 1 | Главная | `index.html` | назначение магазина, кнопки перехода, подборка из 6 книг с переключением жанров, преимущества | выбрать жанр подборки, перейти к книге, положить книгу в корзину |
| 2 | Каталог | `catalog.html` | все книги (18), форма фильтра: поиск, жанр, цена от–до; сортировка; выбор валюты | отфильтровать и отсортировать книги, посмотреть цены в другой валюте |
| 3 | Книга | `book.html?id=N` | обложка, название, автор, описание, год, страницы, переплёт, наличие, цена, блоки «Доставка» и «Возврат», похожие книги | добавить в корзину, добавить в «Прочитать позже» |
| 4 | Корзина (страница действия, группа А) | `cart.html` | выбранные книги, количество, сумма по позициям, доставка, итог | изменить количество, удалить книгу, оформить заказ |
| 5 | Контакты | `contacts.html` | адрес, телефон, e-mail, режим работы, слоган, частые вопросы, форма обратной связи | отправить сообщение |
| — | Вход и регистрация | `login.html` | две формы | войти или создать учётную запись |
| — | Личный кабинет | `account.html` | профиль, список «Прочитать позже», заказы | убрать книгу из списка, выйти |
| — | Ошибка 404 | `404.html` | сообщение и ссылка в каталог | вернуться в каталог |

## Навигация

Меню в шапке на всех страницах: Главная · Каталог · Корзина · Контакты · Войти/Кабинет.
Страница книги открывается из карточек на главной, в каталоге, в корзине и в кабинете.

```
Главная ──┬── Каталог ── Книга ──┐
          ├── Корзина ◄──────────┤
          ├── Контакты           │
          └── Вход ── Кабинет ◄──┘ («Прочитать позже»)
```

## Требования

- семантическая разметка, один `h1` на странице, `alt` у изображений, UTF-8, `lang="ru"`, `viewport`;
- единый файл стилей `css/style.css`, без атрибута `style`; макет на Grid и Flexbox;
- корректное отображение при ширине 360 px без горизонтальной прокрутки;
- изображения обложек — векторные (SVG), 1–2 КБ каждая;
- собственный логотип (`img/logo.svg`).
